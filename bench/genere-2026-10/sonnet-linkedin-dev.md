Ça y est, ma bibliothèque Python de validation de données est open source 🎉

Elle s'appelle [nom-de-la-lib], et elle est disponible dès maintenant sur GitHub : [lien]

Je l'ai commencée pour régler un problème que je rencontrais dans mes propres projets. Valider des données, c'était toujours du code répétitif, des messages d'erreur peu lisibles et des schémas difficiles à maintenir. J'ai fini par en faire une vraie bibliothèque.

Ce qu'elle fait :
✅ Une définition de schémas simple et lisible
✅ Des messages d'erreur clairs, pensés pour être compris par un humain
✅ Des validateurs personnalisables selon vos besoins
✅ Une installation en une commande : pip install [nom-de-la-lib]

Elle n'est pas parfaite, et c'est justement pour ça que je l'ouvre. J'aimerais avoir vos retours, vos idées et vos critiques. Si vous voulez contribuer, les issues et les pull requests sont les bienvenues. Et si vous avez simplement 5 minutes pour l'essayer, dites-moi ce qui vous a plu ou pas.

Une étoile sur le repo m'aiderait aussi à la faire connaître ⭐

Merci à celles et ceux qui m'ont aidé à tester les premières versions.
