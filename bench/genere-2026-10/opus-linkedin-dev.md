🚀 Je viens de publier ma première bibliothèque open source !

Elle s'appelle [NOM] et sert à valider des données en Python, simplement.

Le point de départ est assez banal. Sur mes derniers projets, je réécrivais sans arrêt les mêmes vérifications : un champ obligatoire, un format d'e-mail, une date cohérente, un nombre dans une plage donnée… À force de copier-coller ce code d'un projet à l'autre, j'ai fini par en faire une bibliothèque propre.

Ce qu'elle permet :
✅ décrire ses règles de validation de façon lisible et déclarative
✅ obtenir des messages d'erreur clairs, exploitables côté API comme côté interface
✅ créer ses propres validateurs en quelques lignes
✅ l'intégrer sans friction dans un projet existant, sans dépendance lourde

L'installation se fait en une commande :
pip install [nom-du-package]

C'est une première version. Elle fonctionne et elle est testée, mais elle a forcément des angles morts. C'est justement pour ça que je la partage : vos retours m'intéressent, qu'il s'agisse d'un bug, d'un cas d'usage auquel je n'ai pas pensé ou d'une idée d'amélioration.

Les contributions sont les bienvenues, et une ⭐ sur GitHub aide aussi beaucoup à faire connaître le projet.
