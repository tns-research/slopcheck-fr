# Comment fonctionne le cloud ?

Le mot *cloud*, ou « informatique en nuage », donne parfois l’impression que nos fichiers flottent quelque part dans le ciel. En réalité, le cloud repose sur des équipements très physiques : des ordinateurs puissants, appelés serveurs, installés dans de grands centres de données.

## Des serveurs accessibles par Internet

Lorsque vous enregistrez une photo sur Google Photos, regardez une série sur Netflix ou consultez vos e-mails, votre appareil communique avec un serveur distant par Internet. Ce serveur conserve les données, exécute certaines opérations, puis vous transmet le résultat.

Avant le cloud, les fichiers et les logiciels étaient généralement stockés sur l’ordinateur de l’utilisateur. Avec le cloud, ils peuvent être hébergés sur les serveurs d’une entreprise spécialisée. Vous y accédez ensuite depuis un ordinateur, une tablette ou un téléphone connecté.

Prenons un exemple simple : vous rédigez un document dans un traitement de texte en ligne. Chaque modification est envoyée par Internet vers un serveur, qui sauvegarde le document. Si vous ouvrez ensuite le service sur un autre appareil, le serveur vous renvoie sa version la plus récente.

## Où se trouvent les données ?

Les serveurs sont regroupés dans des bâtiments sécurisés appelés *data centers*. Ceux-ci contiennent parfois des milliers de machines, ainsi que des systèmes d’alimentation, de refroidissement et de protection contre les pannes.

Les fournisseurs de cloud peuvent copier les données dans plusieurs centres. Cette redondance réduit le risque de perdre des informations si un disque tombe en panne ou si un site rencontre un problème. La localisation des données reste néanmoins importante, notamment pour respecter les lois sur la vie privée.

## Trois grands types de services

Le cloud peut fournir différents niveaux de service.

Le **SaaS** (*Software as a Service*) désigne les logiciels accessibles directement en ligne, comme une messagerie ou un outil de visioconférence. L’utilisateur profite du service sans gérer son installation.

Le **PaaS** (*Platform as a Service*) fournit aux développeurs un environnement prêt à accueillir leurs applications. Ils peuvent ainsi se concentrer sur leur code sans administrer tous les serveurs.

Enfin, l’**IaaS** (*Infrastructure as a Service*) permet de louer des ressources informatiques : machines virtuelles, espace de stockage ou réseau. L’entreprise cliente conserve davantage de contrôle, mais doit aussi effectuer plus de configuration.

## Pourquoi utiliser le cloud ?

Son principal avantage est la flexibilité. Une entreprise peut augmenter rapidement ses ressources lorsqu’elle reçoit beaucoup de visiteurs, puis les réduire quand la demande baisse. Elle paie souvent selon son utilisation, au lieu d’acheter immédiatement du matériel coûteux.

Le cloud facilite également l’accès à distance, le partage de documents, les sauvegardes et le travail en équipe. Il ne supprime toutefois pas toutes les contraintes. Une bonne connexion Internet est souvent nécessaire, les coûts doivent être surveillés et la sécurité exige des mots de passe robustes, des sauvegardes et des droits d’accès correctement configurés.

En résumé, le cloud consiste à utiliser, par Internet, les ressources d’ordinateurs distants. Il rend l’informatique plus accessible et adaptable, tout en reposant sur une infrastructure bien réelle qu’il faut protéger et administrer.
